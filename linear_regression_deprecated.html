Predicting Stock Prices with Linear Regression

Machine Learning
• January 19, 2022 • DQ Daniel Querales

A machine learning project to predict Tesla (TSLA) Stock Prices using Python libraries like Pandas, Numpy, SKlearn, and Plotly.

Project Overview

  • Analysis of Tesla stock price dataset (2020 to 2022).
  • Linear regression method used to predict prices using historic values.
  • Tools used: Pandas, Numpy, Plotly, Sk-Learn.
  • Data source: Yahoo Finance API.
  • Educational Purpose Only: Not investment advice.
  • Code available on GitHub Repository.

Objectives

The goal was to train a machine learning model that attempts to predict Tesla (TSLA) stock prices over a two-year range to understand how the pandemic affected the company's performance.

Conclusions

  • The adjusted close price showed a consistent positive slope during the study period.
  • All-time High: $1,243 on 2021-11-04.
  • All-time Low: $70 on 2020-03-18.
  • Max Volume: 304M on 2020-02-04, with spikes in Feb, July, and Dec 2020.
  • Market capitalization peaked on December 18, 2020.
  • Daily volatility averaged around 5%.
  • The 50-200 day moving averages remained positive for the majority of the timeframe.
  • An investment at the start of 2020 would have yielded an approximate 800% return by the end of the study.
  • The Linear Regression model achieved roughly 98% accuracy on test values.
  • Note: Real-world market volatility makes simple linear models insufficient for accurate future forecasting.
